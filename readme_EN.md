## 3. Mathematical Definition & Problem Scope

For a given integer $n$, let $S \subset \{0, 1, \dots, \binom{n}{2}\}$ be a subset of size $n$. The objective is to maximize the number of distinct positive differences generated by pairs in $S$:

$$\Delta(S) = \{ \vert{}x - y\vert{} : x, y \in S, x \neq y \}$$

The sequence $a(n)$ represents the maximum possible size of $\vert{}\Delta(S)\vert{}$ for valid configurations.

def verify_solution(subset):
    differences = set()
    n = len(subset)
    for i in range(n):
        for j in range(i + 1, n):
            differences.add(abs(subset[i] - subset[j]))
    return len(differences)
